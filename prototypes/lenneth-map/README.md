# LennethMap · 横版纵深迷宫编辑器

独立实现的中文地图工具，参考《北欧女神：蕾娜斯》的横版房间与前后景探索结构，采用 MVMap 式工具栏、画布与属性面板。包含原创教学示例；不包含原作地图、ROM 或素材。

从仓库根目录运行 `node server.mjs`，登录后打开 `/lenneth-map/`，使用现有 NAS 后端与账号。完整调研、操作和限制见 [manual.html](manual.html)。独立预览可在本目录运行 `python3 -m http.server 8090 --bind 127.0.0.1`；静态模式仅本机存储，不支持 file://。

- 景深 Z 分层，房间矩形绘制、移动、缩放、搜索及属性。
- 六向显式出口、跨景深连接、单向落下、传送与 AND/OR 机关条件。
- 4× 室内灰盒，十二种对象、移动缩放、标签与条件获取点。
- 可旋转 3D 预览：平移缩放、视角预设、景深间距、室内布局、房间选择与当前视角 PNG；查看不修改工程。
- 当前条件的拓扑可达性、基础结构检查；不模拟角色物理或完整机关时序。
- 撤销重做、工程库、JSON 导入导出、总览/室内 PNG。
- NAS 自动保存与乐观并发保护、本机备份、冲突另存、删除回收站。

格式：`editor: "lenneth", version: 1`。数据存储在现有 boards 卷的 `lennethmap/` 子目录，独立于 MVMap。NAS 只支持一个服务进程操作同一目录。
