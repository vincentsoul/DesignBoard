最终游戏资源：Assets/_Game/Resources/UI/EquipmentSkin/。图集切片由 Unity Editor 导入器生成；32 张独立 PNG 位于 Slices/，图集 Sprite 及九宫格边框记录在 .meta 与 slice-manifest.json 中。
