# 风车谷 · Unity 小队 ARPG 章节原型

在《马里奥与疯兔：王国之战》式的圆润、明快箱庭中，以三人小队进行连续探索和即时战斗。当前章节包含 **8 个箱庭区域、6 场遭遇（23 名敌人）、7 组环境谜题、8 道条件关口、5 个补给宝箱与一条回环捷径**：机关、推箱、转盘和顺序开关控制实际通路，探索路线围绕风车地标形成完整章节。没有掩体、行动点或回合制战斗。本轮在章节基础上加入 **角色等级、随机装备、套装、强化、洗炼、打造与完整冒险存档**。

场景、角色与动作仍使用原创程序化占位资源。装备界面参考用户提供图片的角色展示与装备信息组织方式，展示的角色仍是本项目的原创玩具占位角色，不是图片中的写实角色资产。随机品质、词条、套装和打造规则依据用户选择的“深度刷装”方向设计，不把截图未展示的玩法当作可考证规则。正式角色动画、声音和完整美术资产尚待制作；各次自动检查、构建与实机结果分别记录在文末。

## 打开与运行

1. 在 Unity Hub 中使用 **Unity 6000.6.5f1**，通过 **Add / 从磁盘添加项目** 选择本 README 所在的 `prototypes/toy-garden-unity` 文件夹。
2. 等待包解析、资源导入与脚本编译完成，首次解析通常需要网络。
3. 打开 `Assets/_Game/Scenes/ToyGarden.unity`，也可使用 **Toy Garden → Open Prototype Scene** 菜单，然后点击 **Play**。
4. 点击 Game 窗口获得输入焦点。游戏失焦会暂停；回来后按 **Esc** 或点击 **继续冒险** 继续。

退出 Play 模式后，**Toy Garden → Rebuild Prototype Scene** 可重建默认章节、材质、角色 Prefab 与导航数据。生成器会覆盖默认场景，手工修改前请先另存场景。

**Toy Garden → Build macOS Prototype** 将独立应用输出到 `Builds/ToyGarden.app`。应用与测试结果都是本地验证产物，由 `.gitignore` 排除，不加入源码提交。

## 界面语言

游戏默认使用简体中文，覆盖章节地图、区域名称、目标、队员状态、机关提示、场景路牌、暂停和通关界面。按键名称保留实际键位。HUD、地图和场景文字共用随包内置的 [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf)，不依赖本机是否安装中文字体；原始字体及 SIL Open Font License 1.1 授权文件保留在 `Assets/_Game/Resources/Fonts/`。

## 操作

| 动作 | 键鼠 | 手柄位置（Xbox 名称示例） |
| --- | --- | --- |
| 相机方向移动 | WASD | 左摇杆 |
| 普通攻击 | 鼠标左键 / J | 下侧面键（A） |
| 闪避 | Space | 右侧面键（B） |
| 当前角色技能 | Q | 左侧面键（X） |
| 切换操控角色 | Tab | 左肩键（LB） |
| 机关、推箱、转盘、宝箱、出口 | E | 上侧面键（Y） |
| 章节地图 / 关闭地图 | M | 右肩键（RB） |
| 角色与装备 / 关闭装备界面 | I | 十字键上 |
| 暂停 / 继续；关闭当前地图或装备界面 | Esc | Start |
| 失败或完成后重开章节，保留养成 | R | Select / View |

剑士、重锤手、游侠中一人由玩家操控，两名 AI 跟随并协战。切人保留各自的位置、生命和冷却；也可以点击底部队员卡片切人。普通攻击、技能和闪避可以在连续场景中直接使用。

按 **M** 查看章节地图，显示区域与路线进度；地图打开时游戏暂停，按 M 或 Esc 关闭后继续。按 **I**、手柄十字键上或 HUD 的角色与装备按钮打开装备界面，打开时同样暂停战斗。**装备界面内部目前使用鼠标操作**；手柄支持入口与关闭，尚未提供菜单焦点导航。

**R 只在失败或完成界面重开章节**，普通暂停时不会重开。重开会恢复敌人、谜题、宝箱和章节奖励领取状态，保留三名角色的等级、经验、装备、背包与材料，可再次挑战并获取奖励。

推箱时站到箱子的一侧按 **E**，箱子会朝远离你的方向移动一格。箱子不能离开棋盘或穿过石块；附近的重置机关可以将未完成的推箱谜题恢复初始位置。转盘每按一次 E 改变一个刻度；顺序开关按图案提示的次序激活，按错会重置当前序列。

## 角色与装备养成

剑士、重锤手、游侠各有独立等级、经验和装备栏，最高 **50 级**；每升一级获得攻击与生命加成。金币、矿石、精粹及背包由全队共享。背包最多容纳 **200 件未装备物品**，已经穿戴的装备不占这 200 格。同一物品有唯一 ID，只能由一名队员穿戴；武器有职业限制，其他部位通用。角色必须达到物品等级才能装备。

每名角色有 **武器、头盔、胸甲、腿甲、手套、靴子、戒指、项链**八个栏位。物品详情显示基础属性、随机词条、套装进度，以及换上该装备后整套属性的变化；比较会计入失去或获得的套装效果。攻击、防御、生命、暴击率、暴击伤害、冷却缩减、吸血和移速均接入实际战斗。

| 品质 | 随机词条数量 | 普通奖励掉落概率 |
| --- | --- | --- |
| 普通 | 0 | 40% |
| 精良 | 1 | 28% |
| 稀有 | 2 | 20% |
| 史诗 | 3 | 10% |
| 传说 | 4 | 2% |

词条从攻击、防御、生命、暴击率、暴击伤害、冷却缩减、吸血和移速中抽取，同一物品不会出现重复词条。物品等级影响基础属性及攻击／防御／生命词条数值。掉落品质和词条可用固定随机种子复现，便于验证；定向打造按所选品质生成，不使用上表的随机品质概率。

| 套装 | 2 件效果 | 4 件追加效果 |
| --- | --- | --- |
| 疾风 | 移速 +6% | 冷却缩减 +10%，暴击率 +4% |
| 磐石 | 防御 +12 | 生命 +60，防御 +8 |
| 余烬 | 攻击 +8 | 暴击率 +6%，吸血 +4% |

装备界面提供以下操作：

- **装备与卸下**：从共享背包换装；背包已满时无法卸下装备。
- **锁定与整理**：锁定物品不会被分解或洗炼；支持按品质、部位、等级、套装和获得时间排序。
- **强化**：最高 **+10**，每级使基础属性在未强化数值上增加 8%，不改动随机词条；消耗随强化等级提高。
- **洗炼**：消耗金币与精粹，重新生成整组随机词条，保留物品品质、部位、套装、等级和强化等级。
- **分解**：回收金币、矿石和精粹，需要确认；正在穿戴或已锁定的物品不可分解。
- **定向打造**：选择部位、品质、套装与角色，生成该角色当前等级的装备；武器匹配所选职业。材料不足或背包已满时，不扣费、不生成物品。

新冒险提供 **5000 金币、120 矿石、60 精粹与 8 件背包装备**，可立即体验换装和打造。三名角色最初各穿戴一件不提供额外属性的训练武器，以保留原有裸装战斗数值；训练武器不能强化或洗炼。上述初始赠送只在创建新养成数据时发放，重开章节不会重复发放。

## 章节奖励与保存

战斗奖励按整场遭遇清理完成结算，经验同时发给三名角色；宝箱仍为可选内容。每场战斗、每组机关和每个宝箱在同一次章节挑战中只领取一次。

| 奖励来源 | 金币 | 矿石 | 精粹 | 每名角色经验 | 随机装备 |
| --- | --- | --- | --- | --- | --- |
| 普通遭遇，每场 | 400 | 12 | 5 | 80 | 1 件 |
| 最终守卫遭遇 | 1200 | 30 | 16 | 200 | 1 件 |
| 解开机关，每组 | 150 | 5 | 2 | 35 | — |
| 补给宝箱，每个 | 300 | 10 | 5 | 45 | 1 件 |

完成 6 场战斗、7 组机关并收集 5 个宝箱，合计获得 **5750 金币、175 矿石、80 精粹、每人 1070 经验与 11 件随机装备**。宝箱另为存活队员各恢复 35 点生命。背包已满时仍结算金币、材料与经验，但无法收取新掉落，反馈会说明这一点。

自动存档包含养成数据及完整章节状态：队员与敌人的位置、生命与技能／闪避冷却，当前角色、遭遇状态、机关中间进度、推箱位置、宝箱、奖励领取记录及通关状态。正常游玩期间约 **每 12 秒**保存一次，战斗／机关／宝箱结算、装备操作、角色死亡、通关、章节重开、关闭装备界面、失焦和退出等事件也会触发保存。下一次打开时继续上次冒险；未到保存点的短暂变化可能回退。

存档文件名为 `garden-adventure-v1.json`，目录使用 Unity 的 `Application.persistentDataPath`，不在本项目源码内。写入先使用临时文件，再替换正式存档，并保留 `.bak` 备份。主档无法读取时尝试备份，并保留损坏文件；若无法安全恢复，自动保存暂停，避免覆盖原始数据。装备界面显示保存状态，写入失败不会提示保存成功。存档版本及数值会在读取时检查，越界数据、非法物品引用和重复装备占用会修复或拒绝加载。

## 代码与资源

工程版本为 **Unity 6000.6.5f1、URP 17.6.0、Input System 1.19.0、AI Navigation 2.0.12、Cinemachine 6.6.0**。实际依赖以 `Packages/manifest.json` 和锁文件为准。

| `GardenGame.Persistence` | 奖励去重、完整章节快照、自动存档与备份恢复 |
| `GardenProgression` / `GardenGear` | 等级、共享背包、装备属性、随机词条、套装、打造与序列化校验 |
| `GardenEquipmentUI` | 角色与装备界面、换装对比、锻造操作及角色预览 |
| `GardenChapter` | 区域、关口条件、机关选择、章节目标、补给与解谜进度 |
| `GardenPuzzle` | 拉杆、离散推箱、转盘和顺序机关的状态与复位 |
| `GardenMechanism` / `GardenGate` | 可交互点和实际关门阻挡 |
| `GardenActor` | CharacterController 位移、导航跟随、协战、技能、伤害与生命 |
| `GardenProjectile` | 弹体移动、碰撞、命中与去重 |
| `GardenCameraRig` / `GardenHUD` | 跟随镜头、章节导览与操作反馈 |
| `GardenSceneBuilder`（Editor） | 地形、装饰、角色、谜题、关门、导航及可编辑场景生成 |

| `GardenProgressionTests`（Tests/PlayMode） | 养成模型、交易保护、属性接入、奖励与存档检查 |

运行时输入在 `GardenGame` 中创建 `InputActionMap`，目前没有独立 `.inputactions` 资产。职业裸属性在 `GardenActor` 中配置，等级、装备与套装加成由 `GardenProgression` 汇总后应用；动作采用程序化摆动，攻击由代码时间窗口结算。正式 Animator、动画事件、音效、粒子和 ScriptableObject 数据化属于后续内容。
