# 风车果园 · Unity 小队 ARPG 原型

这个独立 Unity 工程用于验证《马里奥与疯兔：王国之战》式的紧凑箱庭视觉与三人小队即时战斗：在连续场景中自由移动、切换队员、闪避和攻击，通过两场战斗抵达出口。箱庭采用圆润地形、鲜明配色与夸张植物；关卡不包含掩体或回合制战斗。

当前已创建工程、运行时代码和编辑器场景生成器，6 条 Play Mode 自动测试已通过，macOS 独立应用已通过键盘主线通关与重试验收。场景和角色使用程序生成的占位几何体，正式角色动画与美术仍待制作；实际测试范围见下方记录。这是可继续扩展的玩法原型，不代表完整商业游戏。

## 打开与运行

1. 在 Unity Hub 中安装 **Unity 6000.6.5f1**，然后选择 **Add / 从磁盘添加项目**。
2. 选择本 README 所在的 `prototypes/toy-garden-unity` 文件夹。它是 Unity 项目根目录，不要选择外层 `designboard` 仓库。
3. 用上述版本打开工程，等待包解析、资源导入和脚本编译完成。首次解析包通常需要网络。
4. 打开 `Assets/_Game/Scenes/ToyGarden.unity`，也可使用 **Toy Garden → Open Prototype Scene** 菜单，然后点击 **Play**。
5. 点击 Game 窗口，使它获得键盘与鼠标焦点，然后开始移动。切换到其他窗口时游戏会自动暂停；回来后按 **Esc** 或点击 **RESUME** 继续。

需要恢复默认原型布局时，在退出 Play 模式后使用菜单 **Toy Garden → Rebuild Prototype Scene**。`GardenSceneBuilder` 会重建场景、生成材质和角色 Prefab，并烘焙保存 NavMesh；已有布局调整请先另存一份场景。

在编辑器中选择 **Toy Garden → Build macOS Prototype** 可以构建本机应用，默认输出为项目根目录下的 **`Builds/ToyGarden.app`**。构建完成后可从 Finder 打开该应用。`Builds/` 已被忽略，不加入源码提交；实际构建与运行结果见验收记录。

## 操作

| 操作 | 键鼠 | 手柄位置（Xbox 名称示例） |
| --- | --- | --- |
| 相机方向移动 | WASD | 左摇杆 |
| 普通攻击 | 鼠标左键 / J | 下侧面键（A） |
| 闪避 | Space | 右侧面键（B） |
| 当前角色技能 | Q | 左侧面键（X） |
| 切换操控角色 | Tab | 左肩键（LB） |
| 与宝箱、出口等交互 | E | 上侧面键（Y） |
| 暂停 / 继续 | Esc | Start |
| 失败或完成后重试 | R | Select / View |

三名队员为 **Blade、Hammer、Ranger**，玩家操控其中一名，另外两名跟随并参与战斗。切换角色后以新角色的位置继续操作，并保留各自生命和冷却。输入映射由 `GardenGame` 在代码中通过 `InputActionMap` 定义，目前没有独立的 `.inputactions` 资产。

也可以点击屏幕底部的队员卡片切换到该存活队员；点击卡片不会同时触发普通攻击。

## 第一关体验

主线为 **入口 → 普通战 → 坡道 → 精英战 → 出口**，旁侧设有宝箱支路。中央空间留给移动、追击和闪避，装饰集中在路径两侧。本次键盘功能验收的主线路径耗时 **1 分 19 秒**，未领取宝箱；**5–8 分钟**是后续内容与节奏调整目标，尚未达到或验证。

## 技术结构

- `Assets/_Game/Scenes/ToyGarden.unity`：可直接打开并运行的原型场景。
- `Assets/_Game/Scenes/ToyGardenNavMesh.asset`：由生成器烘焙保存的导航网格。
- `Assets/_Game/Materials`、`Meshes`、`Prefabs`：生成的材质、网格与角色源资产；对应 `.meta` 文件应与资产一起保留。
- `Assets/_Game/Materials/Projectile.mat` 与 `Effect.mat`：场景中序列化引用的弹体、预警及攻击效果材质，随构建保留对应 shader。
- `Assets/_Game/Scripts/Runtime`：运行时游戏代码。
- `Assets/_Game/Scripts/Editor/GardenSceneBuilder.cs`：场景生成器与重建菜单。
- `Assets/_Game/Scripts/Editor/GardenBuild.cs`：打开场景与 macOS 构建菜单。
- `Assets/_Game/Tests/PlayMode/GardenPlayModeTests.cs`：6 条 Play Mode 自动测试。
- `Packages/manifest.json` 与 `Packages/packages-lock.json`：Unity 包声明及锁定版本。
- `ProjectSettings/`：Unity 工程设置；版本以 `ProjectVersion.txt` 为准。
- `Library/`、`Temp/`、`Logs/`、`UserSettings/` 等：本机生成内容，由 `.gitignore` 排除。

工程基线为 **Unity 6000.6.5f1、URP 17.6.0、Input System 1.19.0、AI Navigation 2.0.12、Cinemachine 6.6.0**。镜头使用配套包的 `Unity.Cinemachine` 命名空间及 `CinemachineCamera` 新 API；依赖以包清单为准。

生成器使用统一调色板，并在 Linear 色彩空间下转换材质颜色。上层战斗地面为 3.04 m，出口平台为 3.08 m，以小台阶连接层次；场景坐标与导航数据由生成器一起保存。

| 运行时脚本 | 职责 |
| --- | --- |
| `GardenGame` | 小队、输入、切人、遭遇、交互、暂停和重试 |
| `GardenActor` | CharacterController 位移、导航、AI、战斗、生命与角色数值 |
| `GardenProjectile` | 弹体移动、碰撞、命中与去重 |
| `GardenCameraRig` | 共享跟随目标、切人镜头、探索与战斗镜头距离 |
| `GardenHUD` | 队伍状态、目标、交互、暂停和结束提示 |

当前角色和技能数值位于 `GardenActor` 按角色类型分支设置的常量中，尚未提取为 ScriptableObject。攻击采用代码时间驱动的范围或弹体命中，程序化武器摆动和受击闪色用于占位反馈。正式 Animator 动画、动画命中事件、声音与命中特效、技能数据化属于后续制作。

## 后续制作顺序

1. 调整速度、转向、闪避距离、镜头跟随和切人手感。
2. 调整小队跟随间距、协战行为与敌人攻击节奏。
3. 用第一关验证主路、宝箱支路、坡道和战斗区域尺寸。
4. 制作一小块完整美术样板，确定草皮、石路、植被与建筑的统一比例。
5. 提取角色与技能 ScriptableObject 配置，替换正式角色与动画，接入动画命中窗口、声音、粒子和更清晰的受击反馈，再扩展关卡内容。
