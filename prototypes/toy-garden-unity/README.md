# 风车谷 · Unity 小队 ARPG 章节原型

在《马里奥与疯兔：王国之战》式的圆润、明快箱庭中，以三人小队进行连续探索和即时战斗。本轮将最初的双遭遇小场景扩展为 **8 个箱庭区域、6 场遭遇（23 名敌人）、7 组环境谜题、8 道条件关口、5 个补给宝箱与一条回环捷径**：机关、推箱、转盘和顺序开关控制实际通路，探索路线围绕风车地标形成完整章节。没有掩体、行动点或回合制战斗。

场景、角色与动作仍使用原创程序化占位资源。本轮交付重点是章节空间、关口约束、解谜反馈及战斗／探索衔接；正式角色动画、声音和完整美术资产尚待制作。本轮编译、场景生成与 10 项自动测试已通过；独立应用的构建和实机检查见文末记录。

## 打开与运行

1. 在 Unity Hub 中使用 **Unity 6000.6.5f1**，通过 **Add / 从磁盘添加项目** 选择本 README 所在的 `prototypes/toy-garden-unity` 文件夹。
2. 等待包解析、资源导入与脚本编译完成，首次解析通常需要网络。
3. 打开 `Assets/_Game/Scenes/ToyGarden.unity`，也可使用 **Toy Garden → Open Prototype Scene** 菜单，然后点击 **Play**。
4. 点击 Game 窗口获得输入焦点。游戏失焦会暂停；回来后按 **Esc** 或点击 **RESUME** 继续。

退出 Play 模式后，**Toy Garden → Rebuild Prototype Scene** 可重建默认章节、材质、角色 Prefab 与导航数据。生成器会覆盖默认场景，手工修改前请先另存场景。

**Toy Garden → Build macOS Prototype** 将独立应用输出到 `Builds/ToyGarden.app`。应用与测试结果都是本地验证产物，由 `.gitignore` 排除，不加入源码提交。

## 操作

| 动作 | 键鼠 | 手柄位置（Xbox 名称示例） |
| --- | --- | --- |
| 相机方向移动 | WASD | 左摇杆 |
| 普通攻击 | 鼠标左键 / J | 下侧面键（A） |
| 闪避 | Space | 右侧面键（B） |
| 当前角色技能 | Q | 左侧面键（X） |
| 切换操控角色 | Tab | 左肩键（LB） |
| 机关、推箱、转盘、宝箱、出口 | E | 上侧面键（Y） |
| 章节地图 / 关闭地图 | M | 右肩键（RB） |
| 暂停 / 继续；地图中关闭地图 | Esc | Start |
| 失败或完成后重试 | R | Select / View |

Blade、Hammer、Ranger 中一人由玩家操控，两名 AI 跟随并协战。切人保留各自的位置、生命和冷却；也可以点击底部队员卡片切人。普通攻击、技能和闪避可以在连续场景中直接使用。

按 **M** 查看章节地图，显示区域与路线进度；地图打开时游戏暂停，按 M 或 Esc 关闭后继续。**R 只在失败或完成界面重开章节**，普通暂停时不会重开。

推箱时站到箱子的一侧按 **E**，箱子会朝远离你的方向移动一格。箱子不能离开棋盘或穿过石块；附近的重置机关可以将未完成的推箱谜题恢复初始位置。转盘每按一次 E 改变一个刻度；顺序开关按图案提示的次序激活，按错会重置当前序列。

## 章节路线

| 区域 | 空间与内容 | 路线解锁 |
| --- | --- | --- |
| A 入口村落 | 出生、教学机关与远处风车视线 | 拉动开关，开启通向果园的第一道门 |
| B 苹果果园 | 第一场遭遇与第一次推箱 | 清敌并将箱子推上压板，打开水渠坡道 |
| C 水渠工坊 | 高差与水渠意象，三转盘谜题 | 清敌并校准三个转盘，开启钟表庭院路线 |
| D 钟表庭院 | 第二种推箱走位，第三场遭遇 | 清敌并压下目标板，登上风车高地 |
| E 风车高地 | 章节中央地标与休息转折 | 拉动机关，同时开启古树林路线及返回果园的捷径 |
| F 古树林 | 第四场遭遇，三个顺序开关 | 清敌并按正确顺序激活开关，通向遗迹 |
| G 山脊遗迹 | 第五场遭遇，双转盘谜题 | 清敌并完成双转盘，打开山顶关口 |
| H 守护者山顶 | 最终守护者及护卫，章节出口 | 完成全部 6 场遭遇与 7 组谜题后，在出口按 E |

主路为 **A → B → C → D → E → F → G → H**，E 的机关同时开放 **E ↔ B** 的回环捷径。各区由约 8 m 宽的桥或坡道连接，层高由 0 m 逐步上升至 8 m。锁门既阻挡角色也影响导航，满足该门的解谜与战斗条件后才开放。

## 代码与资源

工程版本为 **Unity 6000.6.5f1、URP 17.6.0、Input System 1.19.0、AI Navigation 2.0.12、Cinemachine 6.6.0**。实际依赖以 `Packages/manifest.json` 和锁文件为准。

| 脚本 | 职责 |
| --- | --- |
| `GardenGame` | 小队、输入、切人、遭遇、暂停、失败、通关与重试 |
| `GardenChapter` | 区域、关口条件、机关选择、章节目标、补给与解谜进度 |
| `GardenPuzzle` | 拉杆、离散推箱、转盘和顺序机关的状态与复位 |
| `GardenMechanism` / `GardenGate` | 可交互点和实际关门阻挡 |
| `GardenActor` | CharacterController 位移、导航跟随、协战、技能、伤害与生命 |
| `GardenProjectile` | 弹体移动、碰撞、命中与去重 |
| `GardenCameraRig` / `GardenHUD` | 跟随镜头、章节导览与操作反馈 |
| `GardenSceneBuilder`（Editor） | 地形、装饰、角色、谜题、关门、导航及可编辑场景生成 |
| `GardenPlayModeTests`（Tests/PlayMode） | 真实输入、战斗、行走、解谜、关门条件与章节重置检查 |

运行时输入在 `GardenGame` 中创建 `InputActionMap`，目前没有独立 `.inputactions` 资产。角色数值仍在 `GardenActor` 中配置，动作采用程序化摆动，攻击由代码时间窗口结算；正式 Animator、动画事件、音效、粒子和 ScriptableObject 数据化属于后续内容。
