# 三级回声 · Godot Demo

Godot 4.7.2 的独立第一人称白模试玩。场景外壳来自 Blender 导出的 `assets/whitebox.glb`，移动、碰撞、交互、界面和连锁由 Godot 实现。

## 启动

打开仓库的 `outputs/three-echo-godot/ThreeEcho.app`，点击「开始试玩」。应用内已包含关卡和运行时。

也可以双击本目录的 `启动试玩.command`。它优先打开已打包应用，应用不存在时使用本机 `/Applications/Godot.app` 直接运行源码项目。

编辑关卡时，在 Godot 导入本目录的 `project.godot`，按 F6 运行 `main.tscn`，或按 F5 运行项目。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD |
| 转头 | 鼠标 |
| 拿起、放置 | 走近并瞄准后按 E |
| 射击起爆 | 放下手中晶体，瞄准任意晶体，鼠标左键 |
| 跳跃 | 空格，一米台阶也可自动登上 |
| 重置 | R，恢复晶体、平台和玩家位置 |
| 暂停、释放鼠标 | Esc |

切出游戏窗口会暂停，返回后点击「继续试玩」。准星下方提供拿取、放置、距离与空位提示，可操作目标会高亮。

## 玩法说明

开始界面和 Esc 暂停菜单均有「玩法说明 · 用四张图看懂连锁」。上一页、下一页按顺序展示目标、红晶体触发第一轮、绿色晶体接第二轮、消色晶体接第三轮。每页用彩色卡片展示 C/B/A 当时的颜色和高度。

晶体脚下的颜色决定哪些地面一起改变，晶体自身的颜色决定这些地面变成什么颜色。真正换色的平台上升一米，原本已是目标颜色的平台本轮不动。说明页暂停关卡，点击「回到试玩」保留晶体布置、携带状态与引导进度。引导的放置步骤也说明这样摆放如何接上下一轮。

## 分步引导

默认开启八步参考引导，可自由摆放并从任意晶体启动。右上角给出当前操作，场景中的金色「▼ 当前目标」标记目标位置，并显示距离。目标位于身后时提示转身。引导根据实际晶体布置推进，暂停后保留，R 重置后回到第一步。

1. 在 B 拿起绿色晶体。
2. 放到 A 的任意空基座。
3. 返回入口展台拿起消色晶体。
4. 放到 B 的任意空基座。
5. 返回入口，准备观察。
6. 瞄准 A 上的红色晶体（参考起爆顺序），左键射击。
7. 观察三段换色与升降。
8. 沿 C → B → A 走到出口。

提前射击后，可以继续搬运和射击剩余晶体，也可以按 R 恢复完整参考解法。拿回已放好的晶体时，引导会重新指向它应放置的基座。

## 关卡

平台顺序为入口 → C → B → A → 出口。最初三座平台都在地面，颜色依次为绿、红、蓝。每发生一次换色或消色，受影响的平台上升一米。晶体站在同色或无色地面上被击破时，只消耗晶体，不产生换色。标志物把脚下色域变为自身颜色，受影响区域上的其他晶体继续触发。一轮连锁期间等待结算，结束后可继续搬运和射击尚未消耗的晶体。

红、绿、消色晶体均可搬运和射击。A、B、C 各有三个通用放置位，每个空位接受任意晶体，也可把晶体放回入口展台。初始红色晶体位于 A 的高基座，方便从入口瞄准；该晶体同样可以拿起搬走。

<details>

把绿色晶体搬到 A，把消色晶体搬到 B。返回入口，射击红色晶体。

第一轮 A 蓝变红，触发绿色晶体。第二轮 A、B 红变绿，触发 B 上的消色晶体。第三轮 A、B、C 绿变无色。最终 C=1、B=2、A=3，沿平台中线走到四米高出口即可通关。

## 验证与导出

运行以下命令验证实际物理射线、E 键拿放、占用空位、任意晶体射击、暂停、三段连锁、物理通关和连锁中途重置，同时检查八步参考引导的目标、推进和复位，以及三种晶体在三个平台上的九种放置组合、消色先手、连续起爆、同色与无色地面的击破结果。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path prototypes/three-echo-godot --script res://verify.gd
```

在仓库根目录执行下列命令可重新导出应用，需要 Godot 4.7.2 macOS 导出模板。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path prototypes/three-echo-godot --export-release macOS ../../outputs/three-echo-godot/ThreeEcho.app
```

应用采用本机临时签名。源项目、导入设置和白模资产纳入 Git，`.godot/` 缓存与 `outputs/` 构建产物忽略。
