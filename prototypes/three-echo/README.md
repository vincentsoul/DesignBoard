# 三级回声 · Blender 交互白模

在 Blender 5.2.1 中搭建并验证。源脚本为 `three_echo.py`。交互通过 Blender 视口运行。

## 启动

已打开的会话中，在 3D 视口按 F3，搜索 `Play / first person`。也可在 N 侧栏选择 Three Echo，点击 Play。

重新打开 blend 文件后的启动步骤如下。

1. 顶部选择 Scripting（脚本）工作区。
2. 在文本编辑器的文本下拉菜单中选择 `START_THREE_ECHO.py`。
3. 点击文本编辑器顶部的三角形 Run Script（运行脚本）按钮，也可把鼠标放在文本编辑器内按 Alt+P。
4. 回到 Layout（布局），把鼠标移入 3D 视口。
5. 按 F3，搜索 `Play / first person` 并回车。也可按 N，在 Three Echo 侧栏点击 Play。

运行脚本会重建专用的 Three Echo 场景。

从源代码重建时，在 Blender 文本编辑器打开 `three_echo.py` 并运行即可。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD | 前后左右移动 |
| 鼠标移动 | 转头、抬头与低头，试玩时锁定鼠标 |
| E | 准星对准 2.4 米内的绿色或消色晶体拿起，再对准匹配的空基座放下 |
| 鼠标左键 | 瞄准固定的红色晶体射击，射偏或被遮挡时不会起爆 |
| R | 恢复平台、晶体、初始布置和玩家位置 |
| Esc | 退出试玩，释放鼠标，恢复侧栏 |

瞄准且在操作距离内的晶体显示金黄色高亮和“按 E 拿起”。持有晶体瞄准匹配基座时，基座高亮并显示“按 E 放置”。距离不足时提示走近，不匹配时提示寻找同色基座。移开准星、执行操作或退出试玩会恢复原始材质。瞄准红色晶体时显示左键射击提示。

绿色基座接受绿色晶体，白色基座接受消色晶体。B 平台上有两个独立基座。携带物显示在视野右下方，准星与屏幕底部提示显示操作和结果。放下手中的晶体后才能射击，起爆后需复位才能重新布置。

平台间的小缝可直接跨越，最多自动登上一米高的台阶。走出平台会返回入口。到达出口显示 COMPLETE。切换窗口会结束试玩并释放鼠标，再次点击 Play 可继续。

## 规则与解法

每次换色或消色使实际发生变化的平台升高一米，原本就是目标颜色的平台本轮不会变化。换色触发受影响平台上的其他晶体，依次进入连锁。每轮间隔 1.5 秒。

走到 B，拿起绿色晶体并搬到 A 的绿色基座。回到入口展台拿取消色晶体，搬到 B 的白色基座。回到入口，瞄准最远处 A 平台上的红色晶体射击。起爆后依次发生 A 蓝变红、A 与 B 红变绿、A/B/C 绿变无色。最终 C=1、B=2、A=3，可以沿中线走到四米高的出口。

白模支持鼠标视角、近距离搬运与基座放置、准星射线射击、升降、颜色变化、晶体消耗、错误布置与重新尝试。红色晶体固定，绿色和消色晶体通过换色连锁触发。

## 验证

验证四种布置的最终高度分别为 C/B/A = 0/0/1、0/0/1、0/1/2、1/2/3。实际射线验证包括远距离拒绝拿取、绿色晶体搬到 A、消色晶体搬到 B、不匹配基座拒绝放置、射偏、障碍遮挡和瞄准射击。调用实际视口 modal 更新逻辑，验证三轮动画与晶体消耗，沿中线行走可抵达出口并触发 COMPLETE，以及复位清除携带状态和布置。

`.blend` 试玩文件保存在仓库忽略的 `outputs/three-echo/` 下。源代码纳入版本管理。
