# 三级回声 · Blender 交互白模

在 Blender 5.2.1 中搭建并验证。源脚本为 `three_echo.py`。交互通过 Blender 视口运行。

## 启动

已打开的会话中，在 3D 视口按 F3，搜索 `Play / first person`。也可在 N 侧栏选择 Three Echo，点击 Play。

重新打开 blend 文件后，进入 Scripting 工作区，在文本编辑器选择内嵌的 `START_THREE_ECHO.py`，点击 Run Script。回到 Layout 工作区，再启动 Play。运行脚本会重建专用的 Three Echo 场景，其他场景保留。

从源代码重建时，在 Blender 文本编辑器打开 `three_echo.py` 并运行即可。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD | 前后左右移动 |
| 方向键 | 转头、抬头与低头 |
| G | 绿色晶体在 B 红色基座和 A 蓝色基座之间切换 |
| N | 消色晶体在入口与 B 红色平台之间切换 |
| 空格 | 起爆红色晶体 |
| R | 恢复平台、晶体和玩家位置，保留当前布置选择 |
| Esc | 退出试玩，回到 Blender 编辑操作 |

起爆后需复位才能再次布置。平台间的小缝可直接跨越，最多自动登上一米高的台阶。走出平台会返回入口。到达出口显示 COMPLETE。

## 规则与解法

每次换色或消色使实际发生变化的平台升高一米，原本就是目标颜色的平台本轮不会变化。换色触发受影响平台上的其他晶体，依次进入连锁。每轮间隔 1.5 秒。

把绿色晶体放在 A，消色晶体放在 B。起爆后依次发生 A 蓝变红、A 与 B 红变绿、A/B/C 绿变无色。最终 C=1、B=2、A=3，可以沿中线走到四米高的出口。

白模用快捷键替代实际搬运和瞄准射击，保留第一人称移动、升降、颜色变化、晶体消耗、错误布置与重新尝试。

## 验证

验证四种布置的最终高度分别为 C/B/A = 0/0/1、0/0/1、0/1/2、1/2/3。调用实际视口 modal 更新逻辑，验证平台动画完成后沿中线行走可抵达出口并触发 COMPLETE。

`.blend` 试玩文件保存在仓库忽略的 `outputs/three-echo/` 下。源代码纳入版本管理。
