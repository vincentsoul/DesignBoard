# 方法来源与边界

来源：[UP进化论《SVG是最好的AI编程“语言”》](https://www.bilibili.com/video/BV1BynH65EzX/)，全长约 11:03；整理于 2026-10-28。

- 01:40：提出用 SVG 表达界面，作为 AI 易于生成的视觉中间表示。
- 02:39：先调整 SVG，再要求 AI 按设计实现界面，减少在真实代码里试错。
- 04:24–07:37：从编辑器 UI 延伸到卡牌游戏，展示背景、人物、交互层等拆分与组件状态；SVG 可以承载布局、说明和视觉资源引用。
- 07:37–10:41：SVG 同时提供人可查看的图像与 AI 可读取的结构，作为实现参照，缩小视觉结果的不确定性。

以上是内容意译。作者关于开发提速和还原程度的表述属于个人经验，没有独立基准验证。不要把“SVG 最好”解释成所有项目都应改用 SVG。

本 Skill 增加了工程化建议：沿用现有设计系统、显式布局规则、响应式与行为验证、无障碍语义、资源可移植性，以及区分 SVG 设计表示与运行时资源。这些是实施补充，不是视频逐字结论。视觉约束只能减少歧义，无法保证代码架构、功能或性能正确。
