# 可调整的提示词

这些是起点，按项目约束缩减，不是强制流程。

## SVG 草图

> 先检查项目现有 UI 和组件，为【界面】制作可预览、可编辑的 SVG 草图。参考画布为【宽×高】，主要任务是【任务】，风格和资源沿用【来源】。将主要区域用语义化分组组织，标注必要状态与布局规则。先渲染检查，让我能直接查看草图。

## 局部修改

> 修改【SVG 路径】中的【区域/语义 id】，使【具体变化】。沿用其他区域的视觉规范，渲染查看修改结果，并说明相关状态是否也需要调整。

## 游戏界面分层

> 将【界面】按背景、角色/物体、交互 HUD、浮层组织。需要独立使用的图层保留透明背景，说明尺寸、锚点、顺序和图片来源。列出视差、拖拽等无法由静态稿表达的行为。

## 实现与核对

> 以【SVG 文件】作为本轮视觉参照，在现有【框架】中实现。先列出区域到组件及布局规则的映射，复用已有令牌和资源。渲染相同视口进行对照，修正明显差异；验证【关键交互】和【其他视口】，报告尚未验证的内容。
