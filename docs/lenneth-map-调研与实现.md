# 《北欧女神：蕾娜斯》地图结构与 LennethMap

调研日期：2026-10-27。

原版 PSP 说明书的地点探索部分区分世界地图与横版地点，明确描述左右移动以及从指定入口进入前景或后景。室内动作包括水晶造阶、冻结敌人和推拉物体。因此本次编辑器采用“横版房间 + 独立景深 + 显式出口 + 机关条件”的结构，避免把前后景切换误当成上下楼层。

来源：[PSP 原版说明书镜像](https://manuals.plus/m/673fa72166b67553869be93a206fe794005d1d92bea15ae5bd4695dc4dc0da66)，探索与操作部分；特殊迷宫参考 [Clockwork Mansion](https://valkyrieprofile.fandom.com/wiki/Clockwork_Mansion) 和 [Seraphic Gate](https://valkyrieprofile.fandom.com/wiki/Seraphic_Gate)。说明书为第一方内容的第三方镜像，Wiki 为玩家资料，均不是本工具自己的坐标或格式规范。

## 交付

- 独立实现的中文编辑器，位于 `prototypes/lenneth-map/`，正式路由 `/lenneth-map/`。
- 采用 MVMap 式工具、画布和属性面板，支持房间绘制、移动、缩放、景深过滤、搜索、六向显式出口与连接。
- 支持前后景、横向、楼梯、单向落下、传送和机关门；条件可选 AND/OR。
- 双击房间进入固定 4× 室内网格，十二种对象类型，包括水晶点、冻结敌人、宝箱、机关和推拉物。
- 拓扑可达性预览、结构检查、撤销重做、工程库、JSON 导入导出、总览和室内 PNG。
- NAS 自动保存、错误重试、版本冲突保护、另存副本、本机 IndexedDB 备份与恢复、服务器删除回收站。
- 内置“苍霜遗迹”原创教学迷宫，不提取或复制原作地图及素材。

## 格式与边界

工程使用 `editor: "lenneth", version: 1`，后端 API `/api/lennethmaps`，文件在现有数据卷 `lennethmap/` 下；不与 MVMap JSON 互通。复用文件原子写入、同地图串行队列和 revision 乐观并发检查，提供独立的格式与引用验证，继承现有登录与跨站写入保护。

Z 越大越靠后是编辑器约定，X/Y 是拓扑排版，均不是原作测绘坐标。预览只考虑当前勾选条件与单向通路；室内条件获取点不会自动触发，不模拟物理、消耗道具、计时或旋转机关。一个工程设计一个迷宫，不包含可飞行的世界地图与战斗系统。

完整操作、示例解读与来源见 [编辑器内置说明书](../prototypes/lenneth-map/manual.html)。
