# 矿洞三层：潜入兽矿 · 救出小兽 — 修订方案 V1

本方案保留原图的观察、绕行、伙伴解谜和救援主题，补全可用于灰盒搭建的尺寸与状态规则。数值均为本版本设计假设，不是从原图测量得出，也不是已经实测的结论。配套图： [正交平面图](mine-floor-3-v1.svg)。

## 1. 尺度与角色基准

- 世界单位 1m；平面图每10像素对应1m；辅助网格2×2m；全部空间尺寸按可行走净空计算。
- 玩家身高1.8m，碰撞胶囊直径0.6m；伙伴直径不超过0.8m；NPC身高约1.5m。
- 移速3m/s；不设计跨越裂隙的跳跃能力；小障碍自动跨越高度不超过0.3m。
- 主通道宽4m，笼门宽2m；最小转弯净区4×4m；装饰、门框、矿车和碰撞体不得侵占净空。
- 默认第三人称跟随镜头，目标高度1.4m，后距4m，水平视场角70°；遮挡时收近。参数须通过灰盒测试调整。
- 主能力无需消耗品、无冷却；交互提示距离3m；切换伙伴能力不受队伍站位限制，演出自动就位，避免伙伴寻路造成软锁。

## 3. 高差与返回规则

全层走面Z=0，正常墙高3m，室内净高不低于3m。二层入口Z=+4，坠落至①中央(8,7,0)，软着陆固定恢复操作，不计算坠落伤害；入口不可原路攀回。竖井梯道连接+4、0和−4三个标高，各层设2×2m安全平台，井口护栏仅在梯口断开；梯道停靠时不阻断本层4m宽通行，具体梯槽置于廊道墙外。上下层只定义接口，不虚构其余楼层布局。

竖井自始可用，进入其他楼层前存档；返回保留机关状态。小兽入队前可离开再回来；入队后换层自动随行。不会要求玩家在其他楼层取回完成本关所必需的道具。

## 4. 流程与机制状态

初始已有阿布、小花、小雪。小兽在本关被救出后获得厚土镇脉。

1. **进入与观察**：①落地存档。②设地面观察标记(23,6)，交互时镜头临时移至(23,6,1.6)，朝向矿区提示目标(35,6,1)，让玩家明确矿区位置与求救方向。对话说明可由旧脉绕行。观察不是门控，错过也能完成关卡。
2. **绕行**：沿③前进。岔路采用矿车轨迹、灯光和求救声区分；主路在竖井处明确标牌。允许先去矿区支线或直接去⑤。
3. **定位与安抚**：小雪在⑤囚笼外3m内对求救声使用传音；播放3秒反馈，显露锁链标记并设置 `calmed=true`。笼中小兽因碎布和遮挡在接近前不可见，定位仍有作用。使用传音后遮挡移开，正常显示小兽。
4. **救出小兽**：阿布在锁链3m内使用离火斩，1秒拆链，设置 `chain_removed=true`。若先拆链，小兽仍因惊恐待在笼内，提示传音；只安抚未拆链也不可入队。两状态满足后，笼门滑开，小兽自行走出，设置 `companion_joined=true` 并存档。顺序可交换，推荐先传音。
5. **打开出口**：G3前显示厚土镇脉提示；在塌方西侧3m内使用。小兽2秒稳固地脉，碎石收拢并沉至地面下，最终走面与Z=0齐平；先完成碰撞替换再解除玩家操作锁。设置 `exit_open=true`，出口永久开放并存档。
6. **矿工支线**：G1锁链3m内使用离火斩后永久开门。矿工位于(40,12)，被梁木困住。小花在3m内使用青木生息，2秒撑起梁木后矿工自行脱困，设置 `miner_saved=true`。奖励为世界观线索，无主线钥匙或必需能力。此处不安排敌人，避免原图中“矿工/敌人”身份不清。

所有能力目标要求同侧、直线无遮挡，不可隔墙、隔裂隙或隔楼层使用。传音仅对囚笼目标使用特例：布幕不阻挡声音；实体墙仍阻挡。离火斩对指定锁链生效，不烧毁场景装饰。中断演出可重试；完成状态不可倒退。读档根据状态恢复门、碰撞和队伍，小兽不得重复生成。

## 5. 镜头、引导与节奏

主线中心线约110–130m，含囚笼和出口前的短距离接近；纯行走约40秒。目标首次体验5–7分钟，其余时间来自观察、探索、技能理解和演出。支线目标增加1–2分钟。这些是体验预算，需要以首次游玩测试校准，不能用步行距离直接证明。

沿途每个岔路设置可见路标；已解开的门有稳定灯光反馈；锁链、传音和塌方提示分别使用图标与文字，不仅靠颜色。救援区和出口是安全操作区，无计时压力。此版明确不强制战斗；若后续加入战斗，另行定义敌人、射程、掩体和遭遇预算。

## 6. 灰盒验收清单

以下是待执行的实机验收，不代表已验证通过：

- 使用角色真实碰撞体走完主线、支线、返回和竖井；不穿墙、不被装饰卡住；两单位错身通行。
- 观察标记镜头能穿过双窗看到矿区提示物；玩家不能跳过裂隙，技能不能隔空解门。正常跟随镜头在4m通道转角不穿墙。
- 从两个方向测试每道门，开门不夹人；厚土演出结束后4m通路连续，无隐形残留碰撞。
- 分别测试先拆链、先传音、跳过观察、跳过支线、重复施法、中断施法、提前换层以及返回。
- 在每次状态变化前后退出重进，机关、NPC和队伍恢复一致；角色死亡回到最近检查点，不撤销已保存进度。
- 至少3名首次游玩者测试；记录主线时间、岔路误判、能力提示遗漏和镜头遮挡。若主线中位数不在5–7分钟，调整内容或更新预算，不用降低移速硬凑时长。
