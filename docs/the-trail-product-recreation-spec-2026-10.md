## 1. 文档边界与证据规则

### 1.1 三种信息标记

- **[事实]**：官方商店、发行方发布内容或国服开发组答疑明确支持。
- **[观察]**：媒体试玩或玩家记录支持，可能局限于特定版本、特定时期；不能作为全版本规则。
- **[方案]**：本文为复刻提出的设计、参数和实现规则，均可调整，不能理解为原作真实数据。

各章先列原作依据，再给出复刻需求。第 3—16 章中，凡未单独标为事实或观察的规则、数值、流程、字段、验收目标，**一律属于方案**。原作资料不足的地方采用明确的产品决策，不伪装成历史还原。

### 1.2 调研范围与限制

本次查阅了移动版官方商店、发行方介绍、网易国服开发组答疑、历史媒体试玩及玩家评价。没有实际运行已停运国服，没有获取原作配置、代码、后台数据或完整关卡录像。因此本文可以指导独立实现，但不能保证逐帧、逐项或逐版本一致。

公开页面的“单人”“离线”等标签不能证明全部小镇功能可以离线，也不能证明路上的每个角色都是真人。联网判断优先采用具体版本的官方答疑。

本文复刻的是玩法结构和体验目标。原型使用自制或已授权的名称、角色、模型、图标、音乐与文本；具体素材制作清单见第 15 章。

## 2. 原作产品定位与版本差异

### 2.1 产品定位

[事实] 国际移动版由 22cans 开发、Kongregate 发行，官方介绍将旅程、收集、制作、交易和最终定居建造相连；强调拇指滑动、拖拽操作及风景体验。[S1][S2]

[事实] 网易国服将其定位为徒步生存经营手游。[S3]

**产品分析：玩家是一名带着有限行李的旅行者，通过一次次短途远足，将沿途资源变成继续旅行的能力和安家的积累。**

它具有第三人称移动视角、线性路径、资源管理和经营成长，适合放在“徒步旅行＋轻生存＋制作交易＋家园”的组合中研究。

### 2.2 版本隔离

| 版本 | 资料支持的特点 | 在复刻中的用途 |
| --- | --- | --- |
| 早期国际移动版 | 拇指操作、旅程与营地循环、定居小镇、狗狗伙伴；历史试玩展示空间背包与传送带交易 | 核心体验参考 |
| 网易国服旧版 | 开发组解释国服增强了小镇实时交互，公共柜取物会影响实际共享库存 | 小镇权限与共享设计参考 |
| 2022 国服“新世界” | 新旧版本切换、五种职业专精、多个货币、独立精力、小镇人口与职业分布、宠物能力 | 单独的后续扩展包 |
| PC《The Trail: Frontier Challenge》 | 独立商店产品，存在面向 PC 的版本内容 | 只用于确认版本边界，不作为手游规则补丁 |

依据：[S1][S4][S5][S6]。早期攻略出现 15 人小镇、新世界官方答疑出现 20 人小镇，不应拼成同一套人口规则。

[事实] 国服于 2023 年 2 月 15 日关闭下载、充值及新用户注册，4 月 17 日停止运营。公开公告将原因表述为开发运营策略调整。本文不把“收入不足”“代理到期”等推测当作事实。[S7]

### 2.3 玩家记忆与痛点

[观察] 一篇 TapTap 玩家回忆强调沿途风景、拾取物资、背包负担、营地休息与安家，也提到倒地后物资被他人拾取。这是一名玩家的体验证据，不是用户群体统计。[S8]

[观察] 历史媒体试玩描述了物品在背包中堆叠、溢出以及营地传送带交易；另一些评论指出拖拽识别、背包操作与装备磨损会带来烦躁。[S9][S10][S11]

复刻应保留“我真的带着一包东西旅行”的触感，同时把误触、存档丢失和经济漏洞作为验收重点。

## 3. 复刻目标与范围

### 3.1 五个体验支柱

| 支柱 | 玩家应获得的感觉 | 实现重点 |
| --- | --- | --- |
| 旅程 | 我正在走向新的地方 | 持续前进的角色、地貌变化、下一营地距离 |
| 拾取 | 我发现了有用途的东西 | 清晰资源轮廓、拖拽入包、用途提示 |
| 取舍 | 带什么会改变这次旅行 | 空间、重量、体力、任务需求共同约束 |
| 手艺 | 捡来的材料变得更有价值 | 制作、配方成长、装备改善 |
| 归属 | 我的旅程留下了积累 | 小屋、储物、家具、小镇共同建设 |

### 3.2 MVP 与扩展

| 优先级 | 范围 | 完成定义 |
| --- | --- | --- |
| P0 核心原型 | 竖屏徒步、2 条路线、空间背包、体力、采集、制作、NPC 传送带交易、本地存档 | 连续完成三次“出发—采集—营地—制作—交易” |
| P1 垂直切片 | 3 种地貌、6 条路线、12 配方、任务与装备成长、小屋和仓储 | 45—60 分钟可玩内容，出现明确旅行与安家目标 |
| P2 社交版 | 实际玩家小镇、共享仓库、公共订单、贡献记录 | 并发操作不复制物品、不超卖、不影响个人基础玩法 |
| P3 新世界扩展 | 职业、精力、宠物分工、状态食物、NPC 好感 | 分模块启用，有独立数值与数据迁移方案 |

MVP 的旅行者和交易对象明确使用 NPC。多人服务器尚未完成时，界面不声称其为实时玩家。第一阶段不制作大规模开放世界、实时多人路线或完整商业化。

## 4. 核心循环与玩家旅程

### 4.1 三层循环

```text
短循环：观察路边资源 → 拾取 → 整理背包 → 评估体力 → 继续/减速/吃食物
中循环：出发 → 到达营地 → 加工材料 → 出售与采购 → 更新装备 → 再出发
长循环：解锁地区与配方 → 提高旅行效率 → 定居与建造 → 获得新需求 → 再旅行
```

短循环提供操作乐趣；中循环提供完成感；长循环提供回来的理由。

### 4.2 一次完整会话

1. 在营地查看下一路段的距离、主要资源和预计消耗。
2. 选择一个明确目标，例如收集纤维制作大背包。
3. 带上恢复物品，开始自动沿路径行走。
4. 看见需要的资源，拖入背包；包满后决定整理、丢弃或略过。
5. 体力降低时减速或进食，看到距离营地越来越近。
6. 营地恢复，制作一件成品，获得可见的价值提升。
7. 参加短交易，出售多余材料并购买缺少的部件。
8. 装上新背包、完成任务或给小屋投入材料。
9. 玩家选择继续走、返回已解锁路线，或保存退出。

### 4.3 前 30 分钟引导

以下为原型节奏目标，具体由试玩修订。

| 阶段 | 引导内容 | 保证条件 | 结束回报 |
| --- | --- | --- | --- |
| 0—3 分钟 | 行走、停步、拖拽拾取 | 路径唯一，体力足够，不发生物品损失 | 到达首个营地 |
| 3—7 分钟 | 制作与出售 | 制作材料必定可得，交易由教程 NPC 接单 | 第一次赚到普通货币 |
| 7—12 分钟 | 食物、重量、包满 | 强制教学不会让玩家倒地 | 学会挑选资源 |
| 12—20 分钟 | 图纸任务、装备替换 | 目标材料出现在已解锁路线 | 获得第二档装备 |
| 20—30 分钟 | 定居入口、储物与家具 | 安家材料有保底，允许延期 | 看见第一座小屋与下一地区目标 |

不在第一屏同时展示任务、签到、活动、商店和职业。引导可跳过；跳过后仍能访问教程和新手安全物资。

## 5. 徒步、路线与资源

### 5.1 原作依据

[观察] 早期试玩将旅途描述为沿固定路径前进，可调速度、停下，途中采集、伐木或狩猎；营地连接这些路段。[S9][S11]

### 5.2 行走需求 WALK-01

- 角色沿预设路径自动前进。上滑调快、下滑调慢，速度只有停步、慢走、快走三档，附有可点按替代按钮。
- 路径位置以“路线 ID＋进度”表示，镜头跟随角色；不需要摇杆转向。
- 背包拖拽手势不得触发调速。手势开始时根据触点区域锁定用途，抬手后才解除。
- 停步可以整理背包、检查物品和进食；暂停移动即暂停本路段的体力消耗。
- 打开全屏地图、设置、教程或应用切后台时暂停旅程。NPC 交易也暂停计时。
- 到营地时先锁定旅程结果并保存，再播放到达动画。

### 5.3 地图需求 MAP-01

路线为有向图：营地是节点，路段是边。MVP 主线顺序解锁，已访问营地可选择重走其出发路线。

地图显示已解锁路线、营地、当地资源和首次到达奖励。未解锁地区显示地貌轮廓与一个目标，不公开所有物资表。

路线实例在出发时生成种子；保存后恢复同一个种子、资源状态和路径进度。重启应用不能重刷眼前的稀有物品。

### 5.4 资源需求 RES-01

| 资源类型 | 输入 | 产出规则 | 失败处理 |
| --- | --- | --- | --- |
| 路边散落物 | 拖入背包或点按收集 | 收集一次，生成唯一物品实例 | 无空间则返回原位置 |
| 木材采集点 | 装备工具后完成简单划动/点按 | 固定基础量，工具决定额外收益 | 不扣材料，必要时扣一次工具耐久 |
| 动物资源点 | 使用工具完成简短瞄准 | 成功产出材料，点位有次数限制 | 明确反馈；教程不限重试 |
| 景观发现点 | 经过或点按观察 | 旅行日志、收藏标记 | 无失败，无战斗奖励 |

MVP 首先实现散落物和木材点，动物资源点可推迟。资源刷新优先服从区域主题与任务可达性。

### 5.5 路线内容规则

- 每个路段有起点、至少一个视觉焦点和清晰的终点提示。
- 可交互资源按“组”布置，间隔中留出看景时间。
- 教程路段主线材料固定；普通路段使用资源权重和保底。
- 同时可触达的采集对象建议不超过 3 个，避免拖拽抢夺注意力。
- 稀有资源需有轮廓与音效区别，不能只用颜色表达。
- 玩家错过主线关键材料后，可重走或通过营地购买补齐。

## 6. 背包与物品交互

### 6.1 原作依据

[观察] 历史试玩展示无固定格子的背包，物品可堆叠、挤压、溢出；背包整理本身形成操作乐趣。[S9][S10]

### 6.2 产品需求 BAG-01

背包同时有两个约束：**空间**决定能放多少形状，**重量**决定带这些东西走路的代价。空间未满但很重、空间很满但很轻都应该成立。

MVP 使用二维碰撞轮廓及受控堆叠，呈现实体背包的观感。背包状态采用逻辑坐标保存，避免完全依赖实时物理引擎。

| 属性 | 含义 | 玩家反馈 |
| --- | --- | --- |
| 外形 | 占用背包轮廓，影响摆放 | 物品形状与拖拽预览 |
| 重量 | 累计负重，影响体力消耗 | 当前重量/建议负重 |
| 用途 | 食物、材料、工具、装备、家具等 | 详情标签与任务标记 |
| 堆叠上限 | 同类物品合并限制 | 数量角标 |
| 实例状态 | 耐久、位置、是否保留 | 明确状态图标 |
| 参考价值 | 帮助判断出售或保留 | 制作/交易界面显示 |

### 6.3 拾取与拖拽事务

```text
开始拖拽 → 建立预览 → 判断目标区 → 校验容量/权限
→ 成功：提交物品归属与位置 → 播放反馈 → 保存
→ 失败：返回来源位置 → 提示原因
```

一次拖拽只能提交一次。触摸取消、切后台、断线或目标失效时，预览撤销，物品回到来源；不得同时存在于地面和背包。

### 6.4 交互规则

- 放入合法区域后自动稳定，禁止微小抖动把物品弹出。
- 同种可堆叠物拖到一起会合并；超过上限的余量仍留在原位置。
- 长按显示名称、用途、重量、数量、价值和耐久。
- 任务物品可标记“保留”，出售时二次确认；保留不免除空间和重量。
- 双击食物显示食用按钮，实际恢复量确认后消费；满体力时不误吃。
- 增设快捷整理，将内容摆入合法位置。无法全部摆入时只预览，不自动丢物。
- 丢弃需要拖至明确区域并确认。安全区与系统底部手势区保持间距。

### 6.5 溢出与防误损

原型默认“溢出警告”：上缘超出的物品有晃动和提示，但到警戒时长后回到拾取托盘，玩家可以重新放入或放弃。主线物品不静默消失。

可选的经典模式允许溢出掉落，但必须有倒计时、落物恢复入口和可理解的规则；上线前单独验证。先完成可用性，再评估真实掉落是否增强乐趣。

## 7. 体力、装备与失败恢复

### 7.1 原作依据

[观察] 历史媒体记录体力会随行走下降，食物用于补充，装备存在磨损与旅行能力改善。[S9][S11][S12]

[事实] 新世界官方答疑明确存在旅行体力、异常状态和独立精力系统，食物轮盘在低体力时出现；这不代表旧版也有同一套规则。[S5]

### 7.2 体力需求 STA-01

旅行体力为即时资源，范围 0—100。按固定逻辑时间步更新，并随速度、负重、地形及装备改变消耗。MVP 不引入跨天恢复的精力门槛。

- 体力低于 30 时轻提示，低于 15 时显示食物入口。
- 显示到下一营地的预计体力余量，并在速度/负重改变后刷新。
- 无食物时明确显示“减速”“卸下非必要物品”与“返回上一营地”。
- 到营地后恢复体力，不收普通货币，避免玩家因失败陷入无法继续的循环。
- 应用暂停、看地图和制作不消耗旅行体力。

### 7.3 装备需求 EQUIP-01

MVP 有鞋、外衣、背包和工具四类。鞋改善单位距离消耗，外衣提高旅行体力上限，背包扩大空间与建议负重，工具改善对应采集。

耐久按行走距离或有效采集次数下降，不按真实离线时长下降。损坏后停止加成，物品仍保留，可修理；不突然销毁，也不卸掉已装载物品。

装备替换时校验新背包可用空间；容量不足则留在旧背包并要求整理。禁止换小背包后物品被静默裁掉。

### 7.4 倒地需求 FAIL-01

```text
体力为零 → 停步并暂停损失 → 展示恢复面板
→ 有食物：食用后继续
→ 无食物：免费救援到上一营地，保留任务与装备，结算本段失败
```

原型救援保留全部物品，记录一次失败事件。若后续需要材料惩罚，限于非保留材料且明确展示损失清单；不在新手教学中启用。

原作的掉落被拾取体验是可选还原项。多人版若启用，掉落物所有权、保护时长、领取事务和通知需先实现，不依赖客户端判断。

## 8. 制作、任务与成长

### 8.1 制作需求 CRAFT-01

配方包含解锁条件、输入材料、输出物品、制作时间和用途。营地制作允许点按选择，也支持拖入材料。

执行步骤：选择配方 → 展示已有/缺少材料 → 预览输出空间 → 确认 → 一次性扣料并生成输出 → 保存。输出放不下时进入专用领取托盘，托盘内容也持久化。

- 只扣未保留或经确认的材料。
- 材料不足不创建任务，不部分扣料。
- MVP 普通制作立即完成，可配短动画；不把等待时间当作主要进度限制。
- 可重复制作，但数量受输入材料和输出空间共同约束。
- 接口使用操作 ID，重试返回原结果，不重复产出。

### 8.2 任务需求 QUEST-01

任务分为教学、主线图纸、地区探索、家园需求四类。展示一个主目标和最多两个附加目标。

| 任务条件 | 计数规则 |
| --- | --- |
| 累计拾取 | 物品从世界成功进入背包时计数；重复拖出拖入不重复增加 |
| 持有并提交 | 提交时校验库存并扣除；买来的材料允许提交 |
| 完成制作 | 以成功制作事务计数；加载存档不重复计数 |
| 首次到达 | 营地第一次解锁时计数 |
| 家园投入 | 完成实际材料转移时计数 |

任务前必须校验所需资源位于可达地区；不允许“制作工具才能采材料，而工具配方又需要同一材料”的循环死锁。

### 8.3 成长需求 PROG-01

成长以“新配方—新装备—新路线—新用途”展开，避免全部奖励只提高售价。

初期每 5—10 分钟出现一个可感知进步；中期每次旅行有具体需求；后期允许探索与家园两条目标并行。该节奏是方案目标，不是原作实测时长。

## 9. 营地交易

### 9.1 原作依据

[事实] 国服旧版开发组答疑确认到营地会出现交易入口。[S4]

[观察] 早期媒体试玩描述传送带交易，物品随着移动接近回收端；玩家可买卖，价格随等待发生变化。不同版本的结算与参与者身份没有统一核实。[S9][S10]

### 9.2 交易需求 TRADE-01

MVP 为 60 秒 NPC 交易，传送带从左到右移动。每个物品有明确挂牌价、卖家、剩余停留时间和归属状态。

- 玩家把物品拖到出售区，提交后从背包移入交易托管。
- 买家购买成功时，物品转移并给卖家入账。
- 无买家时，进入回收端并按挂牌基价的固定比例卖给系统。
- NPC 商品可点击购买；先检查货币、背包空间和商品是否可用。
- 交易结束时，仍在带上的玩家商品退回领取托盘，不按满价自动出售。
- 暂停或退出原型交易，不额外刷出新货；保存交易种子与剩余时间。

价格下降、回收折价和结束退回都属于本方案的明确选择，并非原作全版本规则。

### 9.3 挂牌与结算状态

```text
背包物品 → 挂牌托管 → 被购买 / 系统回收 / 结束退回
                         每条分支都只能终结一次
```

成交记录包含订单 ID、物品 ID、双方 ID、货币变化、发生时间和结果。多人版由服务器裁决，显示价格与实际扣款一致。

### 9.4 NPC 行为

NPC 有需求类别、预算和决策冷却，优先购买符合需求的成品。教程固定购买第一次成品；普通阶段不保证全价接盘。

NPC 需求可预告，帮助玩家规划制作。营地缺少必要食物时提供保底供应，不以库存随机性堵住主线。

### 9.5 经济防套利

- 同场购入商品再售出，基础价不提高；交易排名收益不得超过反复倒卖的成本。
- 不设置“最后一秒满价自动售出”特殊通道。
- 商品成交、回收和退回互斥，回调重复不重复加钱。
- 奖励只统计最终完成的合格出售，撤单、自己买回和虚拟价格不计贡献。
- 多人交易增加费用与日常额度前，先使用实际交易日志评估，避免无依据地限制正常用户。

## 10. 小镇、家园与社交

### 10.1 原作依据

[事实] 官方商店强调加入小镇共同建设；旧国服开发组说明共享柜实际取物会影响同镇玩家，区别于其描述的国际版弱联网交互。[S1][S4]

[事实] 新世界答疑说明小镇上限为 20 人，职业布局参与入住安排；本文不将其套用为旧版人口事实。[S5]

### 10.2 单机家园 HOME-01

玩家到达定居节点后获得小屋，初始包含床、私人箱和一个家具位。升级需要普通货币及旅行产出的建材。

- 私人箱增加旅行物资储备，不等于免费扩大随身背包。
- 家具改变可见空间，也可提供轻量便利，首版避免过多叠加数值。
- 小屋升级展示下一级外观与缺少材料。
- 家园物品迁移使用和背包相同的事务机制。
- 小镇入口和下一地区探索同时开放，玩家可选择旅行或经营。

### 10.3 社交版 TOWN-01

建议小镇最多 20 人，以支持新世界方向扩展；这是复刻参数选择。

| 设施 | 作用 | 首版权限 |
| --- | --- | --- |
| 个人小屋 | 私有储物与布置 | 所有人可参观，物品仅屋主操作 |
| 共享仓库 | 捐赠和领取材料 | 只接收明确捐赠物，领取有日志与额度 |
| 公共订单板 | 聚合资源需求 | 全体贡献，统一结算 |
| 议事厅 | 小镇升级 | 镇长可发起，全体可贡献 |
| 餐馆/公共休息点 | 低压力相聚 | 无需每日指定时间参加 |

### 10.4 共享权限

私人物品默认私有。公开共享必须显式转入共享仓库，确认后不能以“只是暂存”为理由自动撤回已被领取物品。

同一件物品同时被两人取走，只有一笔成功；另一笔显示库存已变化。贡献值依据确认后的捐赠价值计算，不因物品再次转回而重复刷取。

搬家保留个人资产与历史日志，不带走共享仓库库存。镇长长期未活跃时提供代理权限流程；小镇满员和无活跃成员时，玩家仍可独立旅行和建造。

### 10.5 低压力社交

路线上的路人仅提供表情、问候与视觉陪伴；强组队不成为主线门槛。公共订单有 NPC 保底完成能力，单人镇也能缓慢成长。

异步角色与真人在线必须分别标识。共享仓库的收取记录可查询，避免把资源减少表现为无法解释的丢失。

## 11. 新世界扩展与商业化

### 11.1 扩展隔离

[事实] 2022 官方答疑确认五种职业专精、绿钞/金条/金马蹄、独立精力、图纸来源与狗狗负重能力。[S5]

这些系统增加成长深度，也增加资源理解成本。核心原型稳定后再依次启用：

1. **职业**：首版采用可切换专精，每种专精提供一种有效制作优势；完整五职业名称、配方和倍率尚未核实。
2. **宠物**：先做跟随与互动，再扩展少量负重帮助；宠物不成为通过基础路线的必要条件。
3. **状态食物**：先做单一旅行体力，后加入最多两种异常状态；每种必须有易懂图标和可得解决物。
4. **NPC 好感**：用于故事、家具或外观，不锁住基本工具。
5. **精力**：若需每日生产预算，只限制额外高收益活动，徒步与看风景始终可进行。

### 11.2 商业化方案

原型不接支付。若发展为独立商业产品，优先评估一次性购买或外观、家具主题包；保留基础旅行、救援与存档功能。

如果使用免费模式，需要分别验证广告与付费的实际接受度。可选激励广告只给额外普通物资，拒绝观看不阻断主线。体力归零不自动跳支付，存档不作为付费功能。

商业化分析不能用国服停运反推原作收入或成本，公开资料不足以支持该结论。

## 13. 原型数值与经济模型

**本章所有数据均为原创试调参数，不是原作数值。**单位“旅行米”是游戏内标尺，可与真实尺度不同。

### 13.1 初始参数

| 参数 | 建议初值 | 调整目的 |
| --- | --- | --- |
| 基础体力 | 100 | 便于估算路线消耗 |
| 慢走速度 | 1.5 旅行米/秒 | 允许观察与整理 |
| 快走速度 | 2.4 旅行米/秒 | 更快到达，单位距离消耗增加 |
| 基础消耗 | 0.18 体力/旅行米 | 首段不依赖食物也能完成 |
| 首段长度 | 240 旅行米 | 慢走约 160 秒 |
| 第二段长度 | 360 旅行米 | 引入负重与进食选择 |
| 初级建议负重 | 8 重量单位 | 易懂、适合少量材料 |
| 常用食物恢复 | 25 体力 | 满值时不消费 |
| NPC 交易时长 | 60 秒 | 营地短循环 |
| 交易回收比例 | 基价的 40% | 区分出售时机与制作价值 |

### 13.2 体力公式

```text
r = 当前重量 / 建议负重
负重系数 = 1 + 0.35 × max(0, r - 0.5)，最大为 2.0
速度系数：慢走 1.0，快走 1.25
装备系数：初级鞋 1.0，二级鞋 0.9
路段耗体 = 距离 × 0.18 × 负重系数 × 速度系数 × 地形系数 × 装备系数
```

示例：首段 240 米，重量 4，建议负重 8，慢走、平地、初级鞋，消耗为 43.2，初始体力足够完成。

第二段 360 米，重量 8，慢走，消耗为 76.14；若改快走，消耗为 95.175。玩家可以清包或带食物。这些数值只用于建立选择，不应让新手靠猜公式活下来。

距离已包含速度影响的时间变化，故“速度系数”表示额外的单位距离消耗，不能再在相同公式中重复乘以速度。

### 13.3 样例配方

以下材料名、价格与制作结果为原型示例。

| 配方 | 输入 | 原料合计基价 | 成品基价 | 额外作用 |
| --- | --- | --- | --- | --- |
| 编织纪念物 | 纤维×3 | 6 | 12 | 第一次制作出售 |
| 烤果串 | 野果×2 | 4 | 6 | 恢复 25 体力 |
| 旅行鞋 | 纤维×3＋皮料×1 | 12 | 24 | 单位距离消耗减少 10% |
| 加固背包 | 纤维×5＋皮料×2 | 22 | 42 | 空间和建议负重提高 |
| 小木凳 | 木料×4 | 12 | 25 | 家园家具与订单 |

基价只用于 NPC 模拟与回收；实际收益取决于是否有买家。买入价格设为基价的 125%，避免纯买入制作形成无需旅行的固定套利。

### 13.4 货币流与资源流

```text
路线采集 → 食物 / 装备 / 可售成品 / 家园建材
NPC 成交与任务 → 普通货币
普通货币 → 补缺材料 / 图纸 / 修理 / 家园升级
共享捐赠 → 小镇进度，贡献只记录一次
```

MVP 使用一种普通货币，避免三币并行掩盖循环问题。普通货币不能直接兑换无限主线奖励；主线任务也不能反复重置领奖。

### 13.5 数值验证方法

每轮试玩记录完整三次旅行：实际耗体、拾取量、丢弃量、制作次数、营地收益、维修支出、食物来源及下一步目标。

重点检查：不拾取能否到营地；合理拾取是否仍可抵达；误采后能否恢复；制作是否有价值；新装备是否可感知；最赚钱配方是否压倒其他玩法。

### 14.3 存档策略 SAVE-01

- 每次采集、食用、制作、交易、任务领取、营地到达和家园转移后保存。
- 使用临时文件写入并原子替换，保留最近有效备份。
- 应用切后台时保存逻辑状态并取消未提交拖拽。
- 物品 UID、操作 ID 与奖励领取状态一并保存，避免重复提交。
- 存档升级先备份，迁移失败则恢复旧文件并提示，不自动清空。
- 本地保存有校验与恢复，但不宣称可完全防作弊。

### 14.4 联网方案

单机原型以本地逻辑为权威；社交版把共享库存、交易货币和公共奖励迁移到服务器权威。迁移不能让旧本地金币直接无限流入多人经济。

请求携带操作 ID 与数据版本。断线后显示“待确认”，重试同一操作；服务器返回原提交结果。客户端不得自行推定成功并再次扣物。

个人看景和已解锁路线支持离线；共享领取、真人交易离线不可提交。恢复网络后按服务器版本同步，不用设备本地时间裁定交易和活动有效期。

### 16.2 性能与可用性目标

在项目选定的最低支持机型上，默认画质徒步场景目标 30 FPS；30 分钟连续游玩无崩溃、无物品丢失。背包建议最多 60 个表现对象，超过后堆叠或简化，不线性增加物理负担。

机型、内存、包体和耗电预算在引擎与目标市场确定后补齐。不能把这些目标写成已通过的性能结果。

首次外部试玩建议招募 8—12 人进行问题发现。目标是多数玩家不用口头指导即可完成首次拾取、制作、出售和再次出发；小样本只诊断可用性，不证明留存或市场规模。

### 16.3 观察指标

| 指标 | 用途 |
| --- | --- |
| 首次拾取/制作/出售完成率 | 找出教学断点 |
| 第三次主动出发比例 | 判断中循环是否建立 |
| 每次旅程停步与整理时间 | 判断背包是否有趣或妨碍旅行 |
| 被拒绝拖拽/取消拖拽次数 | 发现命中区域与交互问题 |
| 倒地率及恢复后继续率 | 判断轻生存压力是否合适 |
| 未消耗材料与最常售配方 | 找出无用途物品与经济偏科 |
| 回家、储物、布置比例 | 判断长循环是否成立 |
| 物品转移异常、存档恢复失败 | 判断可信度与稳定性 |

事件建议：journey_started、pickup_committed、bag_move_failed、food_consumed、camp_reached、craft_completed、trade_settled、rescue_used、home_upgraded。附带版本、路线和会话 ID；不记录不必要的私人信息。

### 16.4 风险与处理

| 风险 | 早期信号 | 优先处理 |
| --- | --- | --- |
| 行走变成等待 | 玩家只盯背包、不看景，或持续快进 | 增加地貌与目标变化，调整资源分组 |
| 背包变成障碍 | 频繁误拖、无法取出底部物品 | 扩大命中区、快捷操作、稳定堆叠 |
| 耐久造成维护疲劳 | 大量时间只在补同一装备 | 延长耐久、加入修理、缩短重复制作 |
| 最优配方垄断 | 所有人只刷同一路线同一物品 | 需求轮换、用途分化、调整成本 |
| 小镇无人卡进度 | 基础升级依赖不存在的职业玩家 | NPC 代工与单人保底 |
| 存档损失破坏信任 | 交易后重登状态冲突 | 原子保存、操作幂等、恢复入口 |
| 看景与限时玩法冲突 | 玩家错过景观、被催促 | 将限时交易集中营地，允许跳过 |
